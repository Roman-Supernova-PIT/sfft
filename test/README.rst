Testing betasfft
================

This repository holds the package only: no tests, examples or test data. To test it, use the upstream
repository betasfft was forked from, the Roman Supernova PIT fork of SFFT, which keeps SFFT's examples
and test data:

    https://github.com/Roman-Supernova-PIT/sfft

The original SFFT, from which that fork started, is https://github.com/thomasvrussell/sfft. If you
cannot find what you need there, ask Lei Hu (leihu@andrew.cmu.edu).
